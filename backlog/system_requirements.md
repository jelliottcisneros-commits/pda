# Minimum Requirements (must be met by the end of the Fall semester)

## As a User

### (Registation Step)

- As a user, I want to be able to input basic information such as name so I can be identified.
- As a user, I should be forced to enter a valid phone number, so that I can be contacted later about assessment.

### (Assessment Step)
- As a user, I want to set up my diversity answers before each exam so they can reflect any changes in me for future exams. 
- As a user, before starting the exam, I want the instructions to be displayed to me so that I know what to do
- As a user, I want to be able to press an answers button so I can select it
- As a user, I want to be able to move onto the next question with some sort of next button so I can continue the exam

### (Post-Assessment Step)
- As a user, I want to be redirected to the 10 to 8 calendar after finishing the assessment
- As a user, I want to be able to set up a consulting time (after assessment) such that I can understand and work with my results

## As an Admin

### (User infos)
- As an admin, I want to be able to view all user data/information such that I can keep track of the data in a database
- As an admin, I want TheSum to have data storage/be hosted such that it can support many users
- As an admin, I want to be able to see user results such that I can consult with them and grab the results even if I lose the email
- As an admin, I want users to register with a name, email, and phone number such that they may be contacted about consultation scheduling and the assessment

### (Assessment Configuration)
- As an admin, I do not want users to be able to go back to past questions such that they are unable to change answers while taking a given exam

### (Other)
- As an admin, I want the assessment to be displayed one question at a time such that users can answer one question at a time/ focus on the given question and not think of them as a collective
- As an admin, I do not want to be users to be able to continue an exam at a later date such that we maintain a state of mind, confidentiality, etc.
- As an admin, I want a question to be completely answered before someone moves onto the next question so that they only focus on one question at a time

# Desired Requirements (must be met by the end of the Spring semester)

## As a User

### (Registation Step)
- As a user, I want to be able to log into the system with my email and password such that I can take the assessment
- As a user, I should be restricted to using my email once, so that I can’t spam the system

### (Assessment Step)
- As a user, I want a tab/page to find the instructions of the exam so I can always review them if needed

### (Post-Assessment Step)
- As a user, I want my results to be automatically emailed to me, such that I can view them.
- As a user I want to be able to download my results so that I can have them locally
- As a user, I want to be able to retake the assessment with new access code and get new results so I can see what has changed over time
- As a user, I want to be able to view/request my past results such I can review them over time and after future exams
- As a user, I want to be able to go back and view the 10 to 8 calendar, also set up an appointment on this calendar

## As an Admin

### (Result infos)
- As an admin, I want to have predefined graphs be automatically generated based on user results such that I do not have to do it manually
- As an admin, I want the results and graphs to be put into a PDF so that the results can be used and sent to the user
- As an admin, I want to have the assessment scores be automatically generated such that results can be provided
- As an admin, I want the user results emailed to me so I can get them in a manner that is convenient to me
- As an admin, when calculating scores, I want the system to accurately assign question category (strength, oneness, etc) based on demographic answers

### (Access code generation)
- As an admin, I want users to use a valid access code to take the assessment such that not just anyone can take it
- As an admin, I can give users a new access code to take the assessment again such that I can see the changes in results over time
- As an admin, I want to be able to enter access codes and their number of available uses into the database such that the system can make use and keep track of them
